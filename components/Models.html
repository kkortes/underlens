Pick the model

Each reviewer and the judge is one string in underlens.config.js. A harness id alone runs that CLI's default model. A model ID picks that model, and the start of the ID picks the harness. The same harness can review more than once, on different models.

export default { reviewers: ['claude-opus-5-5', 'gpt-6.1-sol', 'claude-sonnet-5'], judge: 'claude-fable-5-1', };

These are the strings each CLI's own docs list as of October 2026. The model ID goes to the CLI exactly as you write it, so the CLI and your plan decide what actually runs: a newer ID works the day the CLI takes it, and one it has retired fails validation. A string that starts with no harness id stops the run before anything is reviewed.
