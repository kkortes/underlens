Runs on your own subscriptions

Underlens runs each harness's own CLI in your workflow, signed in with your personal subscription where the vendor allows that in CI. Each one needs a single repository secret. Where a vendor offers no subscription sign-in for CI, this page says so, and that harness runs on an API key billed per use.

Claude 'claude'

Subscription

Needs Claude Pro, Max, Team or Enterprise. Claude Code makes a token meant for CI, and Anthropic documents using it there.

claude setup-token gh secret set CLAUDE_CODE_OAUTH_TOKEN

setup-token opens a browser sign-in and prints a token that lasts one year. Paste it when gh asks. When it expires, run the two commands again.

GPT 'gpt'

Subscription, private repos, about weekly

Needs ChatGPT Plus or Pro, used through the Codex CLI. OpenAI documents signing Codex in on CI with your account, but recommends an API key, and says to use it only in private repositories on runners you trust.

echo 'cli_auth_credentials_store = "file"' >> ~/.codex/config.toml codex login gh secret set CODEX_AUTH_JSON < ~/.codex/auth.json

Codex refreshes its token when it's 8 days old or gets rejected. A GitHub-hosted runner starts from the secret on every run and can't save the refreshed token back, so expect to run codex login and set the secret again about once a week. The validate run warns when that's due. On a self-hosted runner (change runs-on in the workflow), Codex keeps the token in ~/.codex between runs and stays signed in.

GLM 'glm'

Subscription, lightly

Needs a Z.ai GLM Coding Plan. The plan comes with a key that works only inside supported coding tools, and Claude Code is one of them. Underlens runs GLM through Claude Code, pointed at Z.ai's endpoint.

gh secret set GLM_API_KEY

Paste the Coding Plan key from your Z.ai account. Z.ai's terms keep the plan to supported tools, and they neither allow nor forbid running those tools in CI. A nightly review is light use, but Z.ai can still flag heavy automated use.

Gemini 'gemini'

API key, no subscription route

There's no way to use a Gemini subscription in CI. On June 18, 2026 Google stopped Login with Google in Gemini CLI for personal, Google AI Pro and Ultra accounts, and its terms forbid using those sign-in credentials in other tools. Underlens runs Gemini on an AI Studio API key instead.

gh secret set GEMINI_API_KEY

Create the key at aistudio.google.com. It has a free tier; anything beyond that is billed per use.

Grok 'grok'

API key, no subscription route

SuperGrok and X Premium+ sign in to the Grok CLI from a browser, but xAI sends CI and automation to API keys and doesn't document a subscription sign-in for them. Underlens runs Grok on an xAI API key, billed per use.

gh secret set XAI_API_KEY

Create the key at console.x.ai.

The workflow passes all five secrets, so adding a harness to underlens.config.js only takes its secret. You can check each one before the next run: see the last step below.
